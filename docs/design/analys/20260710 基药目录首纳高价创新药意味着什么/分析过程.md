# 分析过程：基药目录首纳高价创新药意味着什么

## 课题概述
基药目录首次批量纳入1类创新药，市场共识是"纳入=放量拐点"。本课题的核心认知差：纳入目录解决的是"能不能配备"，但放量需要的是"能不能处方"——两者之间有一条被严重低估的传导鸿沟。

## 分析过程

### Step 1: 共识解构 (consensus-deconstruction)
**市场共识**：「纳入基药→医院覆盖翻倍→销售放量」
**隐含假设拆解**：
- H1: 医院覆盖数翻倍 → 这些医院会真正采购（忽略DRG/DIP约束）
- H2: 采购后 → 科室会纳入临床路径（忽略医生处方习惯）
- H3: 纳入路径后 → 医生会持续处方（忽略患者支付能力）
- H4: 处方后 → 患者能持续支付（忽略自付比例）

**薄弱环节识别**：每一步都不是100%通过，是逐层衰减的过滤器。

### Step 2: 三维拆解 (topic-decomposition)
按「估值 / 产业 / 政策」三维度：
- **估值半切换**：纳入基药后估值应该怎么调？（市场默认调高，但应分阶段调）
- **覆盖≠放量**：从覆盖到放量中间的产业逻辑是什么？
- **政策传导非线性**：政策→处方→收入的传导为什么不是线性的？

### Step 3: 核心分析方法——多层过滤器模型
构建了从"纳入目录"到"销售放量"之间的多层过滤器：
```
纳入目录 → 医院采购 → 临床路径纳入 → 医生处方习惯 → 患者持续支付 → 销售放量
 100%    →   ~70%   →    ~50%       →    ~30%       →    ~60%      →  最终~6%
```
每层一个过滤器，不是100%通过率，最终从水龙头流出的水量远低于源头供给。

### Step 4: 结论收敛 (investment-convergence)
- "横向覆盖"（药出现在更多医院）vs "纵向深度"（医生在合适患者身上反复开处方）是不同概念
- 基药目录解决横向问题，"986"考核强化横向，但纵向深度需要DRG/DIP政策配合
- 创新药从"纳入"到"放量"的时间差被市场系统性低估
