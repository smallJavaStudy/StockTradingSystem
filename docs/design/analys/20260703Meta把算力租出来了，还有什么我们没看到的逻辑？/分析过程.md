# 分析过程：Meta把算力租出来了，还有什么我们没看到的逻辑？

## 课题概述
Meta开始出租H100/H200等次优代际的推理算力。市场第一反应是"需求旺盛到什么卡都能赚钱"。本课题提示更深层的三组问题：旧卡在什么负载上能跑出可计费Token？Capex见顶是真拐点还是假拐点？算力资产化如何改变板块内部估值？

## 分析过程

### Step 1: 构建新定价框架 (evaluation-metric-shift + framework-innovation)
**核心创新**："每美元Capex可计费Token"定价框架

旧框架：价值 = GPU数量 × 单价
新框架：价值 = f(负载适配性, 利用率, 可计费Token价格, 折旧假设)

**关键洞察**：旧代际GPU能否从"可运行"跨到"可盈利"，取决于具体负载：
- 短文本问答：旧卡堆Batch还能拉高吞吐 ← 有窗口
- 长上下文RAG：吃显存和带宽，窗口正在收窄 ← 有风险
- Agent多轮调用：对时延和抖动敏感 ← 旧卡最难发挥

### Step 2: Capex见顶判断 (capex-roi-analysis)
**四类型区分**：Capex增速掉头，不是简单的"需求见顶"
- 需求驱动型 → 真拐点（需要看ARR/RPO）
- 供给约束缓解型 → 节奏问题
- 会计基数型 → 统计幻象
- 结构切换型 → 投向变了

**三角闭环检验**：Capex—Token—收入
- 如果ARR和RPO还在扩张，Capex放缓多半是节奏调整
- 折旧/收入比比Capex增速更早暴露真实拐点
- Token总量创新高≠闭环成立（需要看"高价值Token占比"）

### Step 3: 算力资产化对估值的影响 (framework-innovation)
Meta下场外租，核心变量不是GPU采购量，而是四种能力的叠加：
1. 自建数据中心
2. 长期电力采购
3. 平台需求底盘
4. 模型开发框架绑定

**对板块的影响**：不是整体等比例抬升，而是"板块内估值标准差扩大"——能验证ROIC的公司向高质量资产重估，其余继续在高波动成长池交易。
