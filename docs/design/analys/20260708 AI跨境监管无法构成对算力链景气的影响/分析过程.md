# 分析过程：AI跨境监管无法构成对算力链景气的影响

## 课题概述
市场担心AI芯片出口管制会导致算力链景气下行。本课题的核心洞察：芯片造出来≠能交付，从流片到客户可用的有效算力要经过五道门——先进封装、HBM搭配、服务器集成、机柜装配、数据中心上架。中间环节才是真正的瓶颈。

## 分析过程

### Step 1: 共识解构 (consensus-deconstruction)
**市场共识**：「芯片管制→国产算力链受损」
**薄弱环节**：市场把"芯片产量"等同于"有效算力供给"。但客户买的不是实验室里的性能曲线，是一柜一柜能上电、能跑满的设备。

### Step 2: 全链路瓶颈分析 (supply-chain-bottleneck)
画出了从芯片到交付的五道门：
```
芯片流片 → 先进封装(CoWoS) → HBM堆叠 → 服务器整机 → 机柜装配 → 数据中心上架 → 客户可用算力
   ✓           ⚠瓶颈          ⚠瓶颈       ⚠约束       ⚠约束        ⚠约束
```
**核心发现**：先进封装和HBM卡在"芯片已造好"和"整机可交付"之间，上游替不了封装厂做堆叠，下游跳不过HBM自己配存储。

### Step 3: 框架创新 (framework-innovation)
**旧框架**：算力链景气 = f(芯片产量)
**新框架**：算力链景气 = f(min(芯片, 封装产能, HBM供给, 整机交付, 数据中心))
评估算力链不再是看最强的一环，而是看最短的板。

### Step 4: 三维结论
- **估值范式切换**：全球前沿vs本土替代形成双轨格局
- **风险收益重估**：训练受限→推理接棒+基础设施瓶颈
- **有效供给卡点**：先进封装+HBM+整机交付的联动瓶颈
