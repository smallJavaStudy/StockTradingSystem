# 分析过程：先进封装能戴维斯双击吗？

## 课题概述
市场用"产能翻倍=利润翻倍"的线性逻辑看先进封装。本课题提出：名义产能≠有效产能，必须通过验证/良率/交付三道门。戴维斯双击能否成立，需要检验三个前置条件。

## 分析过程

### Step 1: 有效产能评估 (effective-capacity-assessment)
**核心框架**：名义产能 → 有效产能的三道过滤器
```
名义产能 (规划数字)
  ↓ 过滤器1: 客户验证（送样→批量→正式采购，约1.5年）
验证产能
  ↓ 过滤器2: 稳态良率（整包良率=所有工序良率的乘积）
良率产能
  ↓ 过滤器3: 持续交付（批次间一致性）
有效产能
```

**时间锁**：今天宣布建线，形成有效产能要等两年+。其间名义数字很漂亮，对利润的贡献近乎为零。

### Step 2: 戴维斯双击三条件检验 (davis-double-play-check)
**条件1**：EPS增速可持续？→ 收入结构变了但利润结构还在追赶
**条件2**：估值提升有支撑？→ 需要报表配合（毛利率改善），光靠叙事推不动
**条件3**：折旧节奏不破坏双击？→ 产能→有效产能转化期，折旧先行、收入滞后

### Step 3: 撤退信号设定 (retreat-signal-detection)
- **预警信号**：毛利率连续两个季度不升反降
- **证伪信号**：有效产能兑现慢于预期、毛利率停在14%不动
- **清仓信号**：折旧/收入比加速上升

### Step 4: 瓶颈资产排序
不是所有封装产能都是平等的。CoWoS-L的壁垒不在能否买到设备，而在能否把细线宽RDL、硅桥对准、Die Bond、微凸点、翘曲控制拧成一个能稳定输出的系统。瓶颈资产的排序决定估值分化。
