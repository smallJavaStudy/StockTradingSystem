# 国产芯片制造认知体系：从一粒沙子到一颗中国芯

> 本文档旨在构建理解国产芯片制造的完整认知框架，覆盖从设计到量产的每一个关键环节、设备、材料及国产化现状。

---

## 第一部分：芯片是什么——基础概念

### 1.1 芯片的本质

芯片（Integrated Circuit, IC）的本质是**在单晶硅片上，通过一系列物理化学工艺，制造出数以亿计的微型晶体管和互连线路，实现特定电子功能的微型电路系统**。

- **基本单元**：晶体管（Transistor）— 现代芯片的基本开关单元，FinFET/GAA等是其不同结构形态
- **制造载体**：晶圆（Wafer）— 通常是12英寸（300mm）或8英寸（200mm）的高纯单晶硅圆片
- **功能层次**：晶体管 → 逻辑门 → 功能模块 → 系统级芯片(SoC)

### 1.2 芯片的分类

| 分类维度 | 类型 | 代表产品 | 国内代表企业 |
|---------|------|---------|------------|
| 按功能 | 逻辑芯片 | CPU、GPU、手机SoC | 海思、紫光展锐 |
| | 存储芯片 | DRAM、NAND Flash、HBM | 长鑫存储、长江存储 |
| | 模拟芯片 | 电源管理、信号链 | 圣邦微、思瑞浦 |
| | 功率芯片 | IGBT、SiC MOSFET | 士兰微、华润微、比亚迪半导体 |
| 按制程 | 先进制程 | 7nm及以下 | 中芯国际（N+2等效7nm） |
| | 成熟制程 | 28nm及以上 | 中芯国际、华虹半导体、晶合集成 |
| 按应用 | 消费电子 | 手机芯片、IoT芯片 | 紫光展锐、乐鑫科技 |
| | 车规芯片 | MCU、IGBT | 比亚迪半导体、芯驰科技 |
| | AI芯片 | 训练/推理加速器 | 海思昇腾、寒武纪 |

## 第二部分：芯片制造全流程总览

芯片制造分为三大阶段，每一阶段又包含多个子环节：

```
【第一阶段：设计】
需求定义 → 架构设计 → RTL编码 → 功能验证 → 逻辑综合 → 物理设计 → 物理验证 → 流片(GDSII)

【第二阶段：晶圆制造 = 前道工艺(FEOL) + 后道工艺(BEOL)】
拉单晶 → 切片/抛光 → FEOL(阱/STI/栅极/源漏等晶体管制造) → BEOL(接触孔/金属层/通孔/钝化等互连)

【第三阶段：封装测试】
晶圆测试(CP) → 划片 → 贴片 → 键合 → 塑封 → 成品测试(FT) → 出货
```

## 第四部分：第二阶段——晶圆制造（Wafer Fabrication）

### 4.0 制造的层级结构

半导体晶圆制造分为三个层次：

```
FEOL (Front-End-of-Line, 前道工艺)：在硅片上制造晶体管
    ↓
MOL (Middle-of-Line, 中道工艺)：晶体管与互连之间的接触连接
    ↓
BEOL (Back-End-of-Line, 后道工艺)：多层金属互连布线
```

---

### 4.1 晶圆准备（Wafer Preparation）

**硅片制造流程**：

```
高纯多晶硅原料 → 拉单晶(Czochralski法) → 单晶硅锭 → 滚磨/定向 → 切片 → 倒角 → 研磨 → 腐蚀 → 抛光(CMP) → 清洗 → 检测 → 成品硅片
```

**关键参数**：
- 直径：主流12英寸(300mm)，成熟8英寸(200mm)，先进研发18英寸(450mm)
- 纯度：11N以上（99.999999999%）
- 平整度：纳米级

**硅片国产化**：
- 全球前五大硅片厂（信越化学、环球晶圆、世创、SUMCO、SK Siltron）占86.6%市场
- 国产：沪硅产业、立昂微、中环股份（TCL中环），12英寸硅片已通过国内晶圆厂验证
- 国产化率：约10-15%

---

### 4.2 前道工艺（FEOL）—— 制造晶体管

FEOL的目标是在裸硅晶圆上制造出数十亿个晶体管。以CMOS工艺为例，标准晶体管制造流程如下：

#### 步骤1：阱形成（Well Formation）
- **目的**：在硅衬底上通过离子注入形成P阱和N阱，为NMOS和PMOS提供基底
- **工艺**：热氧化生长SiO₂ → 光刻定义阱区域 → 离子注入（硼B形成P阱，磷P/砷As形成N阱） → 高温退火激活掺杂
- **关键设备**：离子注入机、高温炉管
- **国产设备**：北方华创（炉管）、山东艾恩（SiC离子注入机）

#### 步骤2：浅槽隔离（STI, Shallow Trench Isolation）
- **目的**：在相邻晶体管之间制造绝缘隔离区，防止漏电
- **工艺**：SiN沉积 → 光刻定义隔离区 → 干法刻蚀挖槽 → CVD填充SiO₂ → CMP平坦化
- **关键设备**：刻蚀机、CVD设备、CMP设备
- **国产设备**：中微公司（刻蚀）、拓荆科技（CVD）、华海清科（CMP）

#### 步骤3：栅极形成（Gate Formation）
- **目的**：制造晶体管的控制极——栅极
- **工艺**：生长栅氧化层(SiO₂或High-k材料HfO₂) → 沉积多晶硅或金属栅 → 光刻+刻蚀定义栅极图形 → 形成侧墙(Spacer)
- **关键材料**：High-k介电材料（HfO₂）、金属栅材料（TiN/TaN/TiAl等）
- **关键设备**：ALD设备、刻蚀机
- **国产设备**：拓荆科技（ALD）、中微公司（刻蚀）

#### 步骤4：源漏形成（Source/Drain Formation）
- **目的**：制造晶体管的源极和漏极
- **工艺**：光刻定义源漏区域 → 离子注入（高剂量掺杂） → 快速热退火(RTA)激活 → 在源漏上形成硅化物(NiSi)降低接触电阻
- **关键设备**：离子注入机、快速热退火设备
- **国产设备**：北方华创、山东艾恩

### 4.3 中道工艺（MOL）—— 接触

- **目的**：在晶体管和金属互连之间建立第一层连接
- **工艺**：沉积介质层 → 光刻定义接触孔 → 刻蚀接触孔 → 沉积阻挡层(Ti/TiN) → 填充钨(W) → CMP平坦化
- **关键设备**：刻蚀机、CVD、CMP

---

### 4.4 后道工艺（BEOL）—— 金属互连

BEOL的目标是在晶圆上制造多层金属导线，将数十亿个晶体管连接成完整电路。

**基本循环**（每层金属重复）：

```
沉积介质层(低k材料) → 光刻定义沟槽/通孔 → 刻蚀沟槽/通孔(双大马士革工艺) → 
沉积阻挡层(Ta/TaN) → 沉积铜种子层 → 电镀填充铜 → CMP平坦化
```

**关键工艺节点**：
- 成熟制程（28nm以上）：8-10层金属，铝互连为主
- 先进制程（14nm以下）：12-15层金属，铜互连+低k介质
- 最先进制程（5nm以下）：15层以上，引入钴(Co)、钌(Ru)等新材料

**BEOL的国产设备**：
- 介质刻蚀：中微公司（已进入5nm及以下）
- 电镀：盛美上海
- CMP：华海清科（国内CMP绝对龙头，份额40%）

### 4.5 晶圆制造的八大标准步骤（泛林集团框架）

| 步骤 | 英文 | 原理 | 关键设备 | 国产设备商 |
|------|------|------|---------|----------|
| 1. 晶圆加工 | Wafer Manufacturing | 单晶硅生长→切片→抛光 | 单晶炉、切片机、抛光机 | 晶盛机电、沪硅产业 |

## 第五部分：第三阶段——封装测试

### 5.1 传统封装流程

```
晶圆测试(CP: Chip Probe) → 背面减薄 → 划片(Dicing) → 贴片(Die Bond) → 引线键合(Wire Bond) → 塑封(Molding)
→ 打标(Marking) → 切筋成型(Trim/Form) → 成品测试(FT: Final Test) → 出货
```

### 5.2 先进封装技术

| 技术 | 原理 | 关键参数 | 应用场景 |
|------|------|---------|---------|
| **FOWLP（扇出型晶圆级封装）** | RDL扩展到芯片外，增加I/O密度 | 线宽/线距L/S <10μm | 手机SoC、射频芯片 |
| **2.5D封装（中介层方案）** | 芯片平铺在硅中介层上，通过TSV/RDL互联 | 间距<20μm | HBM+GPU (CoWoS) |
| **3D封装（垂直堆叠）** | 芯片面对面堆叠，TSV/混合键合互联 | 互联密度远超微凸块 | HBM堆叠、逻辑对逻辑 |
| **SiP（系统级封装）** | 多芯片异质集成在一个封装体内 | — | 车载、工业、IoT |
| **Chiplet（芯粒）** | 不同功能用不同制程制造，然后集成 | — | AI、HPC、服务器CPU |

**CoWoS的三代演进**：
- **CoWoS-S**：硅中介层+TSV，密度最高，HBM+GPU方案
- **CoWoS-R**：RDL中介层（无TSV），降低成本
- **CoWoS-L**：混合硅桥与RDL，平衡性能和成本

### 5.3 国产封测现状

中国封测环节较为成熟，长电科技、通富微电、华天科技已进入全球前十大封测企业：
- **长电科技**：全球第三，已实现FOWLP、2.5D量产
- **通富微电**：绑定AMD，先进封装布局深入
- **华天科技**：在CIS封装、Fan-out等领域有竞争力

## 第九部分：一颗中国芯片的真实制造路径

以一颗典型的国产28nm逻辑芯片为例（中芯国际/华虹代工）：

```
【设计端】
海思/紫光展锐用Synopsys/Cadence EDA工具设计 → GDSII文件交付中芯国际

【晶圆制造 - 中芯国际北京/上海】
12英寸硅片(沪硅/立昂微) → 
FEOL: 阱形成(北方华创炉管) → STI隔离(中微刻蚀+拓荆CVD+华海CMP) → 
       栅极形成(拓荆ALD+中微刻蚀) → 源漏形成(北方华创/中科信离子注入) →
MOL: 接触孔(中微刻蚀+拓荆CVD+华海CMP) →
BEOL: 8-10层金属互连(每层：中微刻蚀+北方华创PVD+盛美电镀+华海CMP) →

【测试封装】
CP测试(长川/华峰测试机) → 划片 → 长电科技/通富微电封装 → FT测试 → 出货

【关键进口环节（仍然依赖海外）】
- 光刻机：ASML DUV（上海微电子28nm DUV可用但产能有限）
- 部分高端光刻胶：JSR/TOK
- 部分检测设备：KLA
- 部分离子注入机：应用材料
```

## 第十部分：理解框架的七个关键问题

在阅读任何半导体分析报告时，都应回归以下基线问题：

1. **这颗芯片的制程节点是什么？** 成熟制程(28nm+)→国产化可行性高；先进制程(14nm-)→受多重约束
2. **制造它需要哪些关键设备？** 每种设备的国产化率和供应商是谁？
3. **需要哪些关键材料？** 硅片/光刻胶/特气/靶材的国产化程度如何？
4. **产能在哪里？** 中芯国际/华虹/晶合/长存/长鑫的具体产线和产能？
5. **美国制裁影响多大？** 该环节是否受EAR、BIS等出口管制限制？
6. **中国在哪个环节有突破、哪个环节最脆弱？** 最脆弱环节=最大的投资弹性
7. **从PPT到量产要多长时间？** 认证周期、良率爬坡周期、设备交期各是多长？
