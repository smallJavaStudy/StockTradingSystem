## 三、半导体产业链定位分析

鼎龙股份是中国**半导体材料**赛道最核心的标的之一，我将其所在产业链位置梳理如下：

### 3.1 核心业务矩阵

```
鼎龙股份 ─┬─ CMP抛光垫 ────── 国内唯一突破、市占率~40%
          ├─ CMP抛光液/清洗液 ── 第二增长曲线，放量中
          ├─ 晶圆光刻胶───专项推进中 
          ├─ 先进封装材料 ── PI胶、临时键合胶
          └─ 柔性显示材料 ── PI浆料（YPI、CPI）
          总股本：9.53亿股
```

### 3.2 竞争格局

| 产品 | 全球龙头 | 鼎龙定位 | 国产化空间 |
|------|----------|----------|------------|
| CMP抛光垫 | Cabot/陶氏/3M | **国内第一** | 材料国产化率<20%→2030目标50% |
| CMP抛光液 | Cabot/日立化成 | 国内第二梯队（追赶安集） | 增速最快环节 |
| PI浆料（柔性显示） | 日本宇部/Kolon | 国内率先量产 | OLED扩产拉动 |

### 3.3 业绩驱动逻辑

1. **材料国产化加速**：设备国产化率已从4%(2018)→13%(2024)，但材料国产化更滞后，现在是政策重点突破方向
2. **大基金三期(3440亿)** 明确聚焦卡脖子环节，CMP材料是重中之重
3. **毛利率持续提升**：从2022年的**45%**→2024年的**47%**→2026Q1的**55%**，表明产品结构升级+规模效应
4. **净利增速远超营收增速**：2025年报营收+9.6%，但净利润+38.2%；2026Q1营收+23.8%，净利+**78%**→**运营杠杆释放**

## 六、关键问题与讨论点

### 🔴 看多因素：
1. **业绩加速明显**：2025年净利+38%，2026Q1净利**+78%**，是典型的**业绩加速拐点**信号
2. **毛利率突破55%**：近3年毛利率从45%→55%，说明产品结构优化（向高毛利高端材料切换）
3. **运营杠杆释放**：营收增长23.8%，净利润增长78%，CMP材料属于**高固定成本+低变动成本**的业务结构
4. **政策背书**：大基金三期3440亿聚焦材料，鼎龙是CMP材料绝对龙头
5. **估值消化**：从高点1373元回撤至77元（~44%），PE从高位大幅回落

### 🔴 看空/风险因素：
1. **PE仍超100x**（TTM），即使2026年EPS到1.06元，PE仍~73x，安全边际不足
2. **PB 13.4x** 在材料公司中偏贵
3. **客户扩产存不确定性**：中芯等受制裁影响，扩产节奏可能慢于预期
4. **竞争加剧**：安集科技在抛光液领域实力更强，CMP垫面临海外龙头降价压力
