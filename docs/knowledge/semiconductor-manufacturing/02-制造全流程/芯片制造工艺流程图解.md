# 芯片制造工艺流程图解：从沙子到芯片的55个关键步骤

## 一、工艺全貌

一颗芯片的制造需要经过**数百道工艺、耗时3-6个月**。核心工艺循环如下：

```
              ┌──────────────────────────┐
              │     薄膜沉积             │
              │  (CVD/PVD/ALD)          │
              └──────────┬───────────────┘
                         │
    ┌────────────────────┼────────────────────┐
    │                    │                    │
    ▼                    ▼                    ▼
┌─────────┐      ┌──────────┐        ┌──────────┐
│  光刻    │ ──→  │   刻蚀   │  ──→  │ 离子注入  │
│(Photo)  │      │ (Etch)   │       │(Implant) │
└─────────┘      └──────────┘       └──────────┘
    │                                       │
    └───────────────  CMP  ←────────────────┘
                         │
              ┌──────────┴───────────┐
              │     清洗 (Clean)      │
              └──────────────────────┘

  核心循环(BEOL最频繁): 沉积 → 光刻 → 刻蚀 → 清洗
  每层金属约需循环2-3次，10层金属=20-30次循环
```

## 二、FEOL（前道工艺）— 晶体管制造流程

### 阶段1：晶圆准备
```
步骤1: 高纯多晶硅原料（11N纯度, 99.999999999%）
步骤2: Czochralski拉单晶（1415°C熔融硅中拉出单晶锭）
步骤3: 单晶锭滚磨/定向（确定<100>或<111>晶向）
步骤4: 金刚石锯切片（厚度约775μm）
步骤5: 倒角（去除边缘应力集中）
步骤6: 双面研磨（减薄至目标厚度）
步骤7: 化学腐蚀（去除研磨损伤层）
步骤8: CMP抛光（达到原子级平整度, Ra<0.1nm）
步骤9: 超纯水+化学清洗
步骤10: 检测（颗粒数、平整度、电阻率）
```
**国产设备覆盖**：拉单晶（晶盛机电）、切片/研磨/抛光设备仍有部分依赖进口

### 阶段2：FEOL晶体管制造（以28nm HKMG CMOS为例）

```
【阱形成】(Well Formation)
步骤11: 热氧化生长SiO₂牺牲层（~10-20nm）
步骤12: 光刻-阱层（定义P阱和N阱区域）
步骤13: 离子注入-硼(B)形成P阱
步骤14: 离子注入-磷(P)/砷(As)形成N阱
步骤15: 高温退火（激活掺杂, 修复晶格损伤, 900-1100°C）

【浅槽隔离】(STI)
步骤16: LPCVD沉积SiN硬掩模（~100nm）
步骤17: 光刻-STI层（定义隔离区图形）
步骤18: 干法刻蚀SiN+Si（挖出~300-500nm深的沟槽）
步骤19: 热氧化生长沟槽内衬氧化层
步骤20: HDPCVD/SACVD填充SiO₂
步骤21: CMP平坦化（停于SiN层）
步骤22: 湿法去除SiN硬掩模

【栅极形成】(Gate First HKMG)
步骤23: 清洗（HF-last获得氢钝化表面）
步骤24: ALD沉积界面层SiO₂（~0.5-1nm）
步骤25: ALD沉积High-k介质HfO₂（~2-3nm）
步骤26: PVD沉积金属栅叠层（TiN/TaN/TiAl等功函数金属）
步骤27: CVD沉积多晶硅覆盖层
步骤28: 光刻-栅极层（最关键的CD控制层）
步骤29: 干法刻蚀多晶硅+金属+High-k（极高选择比要求）
步骤30: ALD沉积SiN侧墙(Spacer)

【源漏形成】(S/D Formation)
步骤31: 光刻-NMOS源漏区
步骤32: 离子注入-N型掺杂（As/P, 高剂量）
步骤33: 光刻-PMOS源漏区
步骤34: 离子注入-P型掺杂（B/BF₂, 高剂量）
步骤35: 快速热退火(RTA, Spike Anneal ~1050°C, <1秒)
步骤36: 选择性外延生长SiGe(PMOS)/SiC(NMOS)提升应力
步骤37: 沉积Ni → 退火形成NiSi硅化物（降低接触电阻）
步骤38: 选择性去除未反应Ni

【MOL接触】
步骤39: CVD沉积接触刻蚀停止层(SiN) + 介质层(SiO₂)
步骤40: 光刻-接触孔层
步骤41: 干法刻蚀接触孔（高深宽比, >10:1）
步骤42: PVD沉积Ti/TiN阻挡层+粘附层
步骤43: CVD沉积W（钨）填充
步骤44: CMP去除多余W
```

### 阶段3：BEOL（后道工艺）— 金属互连

```
【每层金属的标准循环】（先进制程约12-15层）
步骤45: PECVD沉积低k介质层(SiCOH, k<3.0)
步骤46: 光刻-金属沟槽 + 光刻-通孔（双大马士革工艺）
步骤47: 干法刻蚀沟槽+通孔（先进制程用ALE原子层刻蚀）
步骤48: 去除光刻胶 + 清洗
步骤49: PVD沉积Ta/TaN扩散阻挡层
步骤50: PVD沉积Cu种子层
步骤51: 电镀填充Cu（Bottom-up Fill）
步骤52: 退火（稳定Cu晶粒）
步骤53: CMP去除多余Cu（Dishing/Erosion控制）

【钝化与焊盘】
步骤54: 沉积钝化层(SiN/SiO₂叠层)
步骤55: 光刻+刻蚀打开焊盘开口(Pad Opening)
```

## 三、不同制程节点的关键差异

| 工艺特征 | 28nm | 14nm/7nm | 5nm及以下 |
|---------|------|---------|----------|
| 晶体管结构 | Planar HKMG | FinFET | GAA/Nanosheet |
| 光刻技术 | 193nm ArF浸没式+单次曝光 | 193nm浸没式+多重曝光(LELE/SADP) | EUV+多重曝光 |
| High-k/MG | Gate First 或 Gate Last | Gate Last (RMG) | Gate Last |
| BEOL金属层 | 8-10层 | 12-13层 | 15层+ |
| 互连材料 | Cu + SiO₂/FSG | Cu + ULK(k<2.5) | Cu + 气隙/Co盖帽 |
| 最小金属间距 | ~90nm | ~50nm(7nm) | ~30nm |
| 光罩层数 | ~40-50层 | ~60-80层 | ~80-100层+ |

## 四、关键工艺窗口的数值概念

| 工艺参数 | 28nm | 14nm/7nm | 5nm |
|---------|------|---------|-----|
| 栅极长度(Lg) | ~30nm | ~20nm/14nm | ~12nm |
| 鳍片宽度(Wfin) | N/A(Planar) | ~8nm/6nm | ~5nm(Nanosheet) |
| 栅极CD控制 | ±3nm | ±2nm | ±1nm |
| 套刻精度(Overlay) | ±5nm | ±3nm | ±1.5nm |
| 缺陷密度(D₀) | <0.1/cm² | <0.05/cm² | <0.02/cm² |
| CMP非均匀性 | <5% | <3% | <1% |

## 五、中国芯片制造的"三道光罩门槛"

国产芯片制造面临光刻技术路线的独特约束：

```
【第一道门槛 - 成熟制程(28nm及以上)】
光刻方案：193nm ArF干式光刻机 + 单次曝光
光罩层数：~40层
国产光刻机：上海微电子28nm DUV可覆盖（国产化率>70%）
设备约束：光刻机不受美国EAR直接限制，DUV多重曝光可行但成本上升
结论：基本可行，成本接近国际水平

【第二道门槛 - 先进制程(14nm-7nm)】  
光刻方案：193nm ArF浸没式 + SADP/SAQP多重曝光
光罩层数：~60-80层
国产光刻机：需ASML NXT系列（受美国施压荷兰限制出口）
设备约束：美国实体清单限制，中芯国际无法获得EUV，DUV浸没式需许可证
结论：可制造但成本高（多重曝光增加光罩层数和工艺周期），良率挑战大

【第三道门槛 - 最先进制程(5nm及以下)】
光刻方案：EUV(13.5nm) + 193nm浸没式
光罩层数：~80-100层+
国产光刻机：无国产EUV可用（ASML EUV完全禁售中国）
设备约束：全部EUV光罩工艺被卡，纯DUV路线到5nm基本不可行
结论：当前不可行，需等待国产EUV突破或另辟蹊径（系统级效率/先进封装/异质集成）
```
