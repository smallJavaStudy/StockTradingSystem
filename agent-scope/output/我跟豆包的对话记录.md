# 直接给结论：这一轮是**需求拉动型涨价**，和工业革命“上游资源通吃、中下游被挤压”的逻辑完全不一样。

## 一、全球涨价先后顺序：功率半导体不是最先发起的，属于第二波
涨价从**离AI需求最近、供需缺口最大的环节**先启动，逐步往上游传导，顺序是：
1. **第一波（最早、涨幅最大）：存储芯片（DRAM/NAND/HBM）**
   - 2025年底触底，2026年Q1正式暴涨，Q1 DRAM合约价环比涨90%+，Q2继续涨50%+，Q3预计再涨30%+，是本轮涨价的绝对龙头，AI服务器对存储的需求最直接、缺口最大。
2. **第二波：模拟芯片 + 功率半导体（同步）**
   - 2026年4月第一轮试探涨价，7月第二轮集中落地（英飞凌、TI海外大厂带头，国内跟进），功率涨10%-25%，属于AI需求传导到电源侧的第二波行情，不是最早启动的。
3. **第三波：晶圆代工（成熟制程）**
   - 2026年Q2开始上调8英寸晶圆报价，比芯片端晚1-2个季度，因为功率、模拟、存储都挤8英寸产能，满产后代工价才传导上涨。
4. **第四波（最晚、涨幅最小）：上游硅片等材料**
   - 6-7月才开启第二轮提价，普通12英寸硅片涨5%-8%，只有AI专用高端硅片涨18%-22%，是整个产业链最后传导到的环节。

## 二、产业链位置定位
### 1. 硅片：**绝对最上游**
和工业革命里的煤炭、铁矿石地位完全一致，是半导体产业链最顶端的基础原材料，所有芯片都要先做硅片，属于产业链最上游。

### 2. 功率半导体：**中游成品芯片（偏下游需求端）**
- 上游：硅片 → 晶圆代工 → 封装材料
- 自身：属于**成品芯片环节**，是直接卖给下游的终端元器件
- 下游：AI服务器电源、新能源车电控、光伏逆变器等终端应用
- 不是末端，末端是服务器、汽车、手机这些整机产品。

## 三、和工业革命的核心区别：不是上游吃饱，是“缺口最大的环节”吃饱
### 传统工业革命逻辑（资源型涨价）
上游原材料（煤、铁）供给刚性、稀缺 → 上游定价权拉满 → 中下游制造业成本被挤压，利润全在上游。

### 本轮AI半导体涨价逻辑（需求拉动型）
稀缺的**不是上游硅片材料，而是特定品类的芯片产能**（高端存储、车规功率、AI电源芯片），上游硅片整体产能是充足的，只有少数高端品类紧缺，所以利润分配完全反过来：
1. **最赚钱（第一梯队）：存储、高端功率/模拟芯片厂（尤其是IDM模式）**
   - 比如三星二季度营业利润同比暴涨18倍，全靠存储涨价；自有晶圆厂的IDM（士兰微、华润微、扬杰）成本固定，涨价几乎全转化为利润，弹性最大。
2. **第二梯队：成熟制程晶圆代工厂**
   产能满载+代工涨价，量价齐升，但利润弹性小于芯片厂。
3. **最不赚钱（弹性最小）：上游硅片、普通材料厂**
   涨幅小、传导慢，大部分品类只是止跌回升，远没到“通吃”的程度。

### 真正被挤压的是最末端
被成本涨价压缩利润的是**最下游的整机厂**（服务器厂商、手机厂商、家电厂商），不是中游的芯片厂；中游纯Fabless设计公司（比如富满微）会被代工涨价吃掉一部分利润，所以弹性不如IDM。
