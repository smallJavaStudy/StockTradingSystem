# 深度研究技能组

## 技能总览

| 组 | 技能 | 用途 |
|----|------|------|
| 研究设计 | consensus-deconstruction | 解构市场共识，找到认知差 |
| 研究设计 | topic-decomposition | 将大课题拆成3个独立子命题 |
| 研究设计 | evaluation-metric-shift | 当旧评估指标失效时建立新量纲 |
| 研究设计 | pdf-reader | PDF深度阅读——CID字体PDF的OCR提取+结构化 |
| 产业穿透 | supply-chain-bottleneck | 全链路瓶颈分析 |
| 产业穿透 | effective-capacity-assessment | 名义产能→有效产能的评估 |
| 产业穿透 | structural-vs-cyclical | 判断趋势是周期还是结构性变化 |
| 框架构建 | framework-innovation | 构建替代旧框架的新分析框架 |
| 框架构建 | davis-double-play-check | 检验双击成立条件+设定证伪信号 |
| 框架构建 | capex-roi-analysis | 评估Capex效率与回报 |
| 风险验证 | retreat-signal-detection | 设定投资假设的退出条件 |
| 风险验证 | supply-chain-vulnerability | 评估供应链薄弱环节 |
| 结论输出 | investment-convergence | 多维度收束为统一投资判断 |
| 结论输出 | structured-reporting | 按标准结构输出研究报告 |

## 标准研究流程

```
1. consensus-deconstruction      → 找到认知差
2. topic-decomposition           → 拆成3个维度
3. [可选] evaluation-metric-shift → 必要时更换评估量纲
4. 对每个维度独立应用：
   - supply-chain-bottleneck
   - effective-capacity-assessment
   - structural-vs-cyclical
   - framework-innovation
   - davis-double-play-check
   - capex-roi-analysis
5. supply-chain-vulnerability    → 评估剩余风险
6. retreat-signal-detection      → 设定退出条件
7. investment-convergence        → 收束为统一判断
8. structured-reporting          → 输出标准报告
```
