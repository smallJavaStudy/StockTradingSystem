# 课题三维拆解

## 何时使用

- 面对一个复杂的投资课题，不知道从哪里开始研究
- 课题太宏大，无法用单一维度说清楚
- 需要确保研究覆盖了课题的多个关键侧面

## 拆解原则

### 三维度框架

对一个投资命题，从三个独立维度拆解。三维度的选择取决于课题性质：

**产业链课题 → 「供给 / 需求 / 定价」**
- 供给端：产能、技术壁垒、竞争对手
- 需求端：下游景气度、替代风险、需求弹性
- 定价端：估值锚、定价框架、市场定价偏差

**政策/事件课题 → 「产业影响 / 估值重估 / 风险收益」**
- 产业影响：政策对行业基本面的实质性改变
- 估值重估：市场定价逻辑的变化
- 风险收益：在新框架下重估风险收益比

**竞争格局课题 → 「产品力 / 生态壁垒 / 成本结构」**
- 产品力：产品本身的竞争力
- 生态壁垒：网络效应、转换成本
- 成本结构：定价策略与盈利可持续性

### 三维度的独立性检验

三个维度必须满足：
- 每个维度的结论不能从另一个维度直接推导
- 三个维度可以独立研究（不依赖彼此的结果）
- 三个维度合在一起覆盖课题的核心矛盾

如果两个维度可以合并而不丢失信息，那只需要两个维度。

## 输出格式

```
课题: [一句话表述]

维度1: [名称] — [要回答的核心问题]
  关键词: [3-5个关键词]
  研究方法: [需要什么样的分析/数据]

维度2: [名称] — [要回答的核心问题]
  关键词: [3-5个关键词]
  研究方法: [需要什么样的分析/数据]

维度3: [名称] — [要回答的核心问题]
  关键词: [3-5个关键词]
  研究方法: [需要什么样的分析/数据]

交叉验证: [三个维度如何互相验证/互相约束]
```

## 典型案例

| 课题 | 维度1 | 维度2 | 维度3 |
|------|------|------|------|
| 先进封装能戴维斯双击吗？ | 有效产能（供给端验证） | 双击条件（EPS+估值双升前置条件） | 撤退信号（证伪条件） |
| Meta出租算力 | 旧卡延寿定价（资产定价） | Capex见顶判断（周期检验） | 算力资产化（配置视角） |
| AI电力设备 | SOFC（架构价值） | 变压器（制造壁垒） | 燃气轮机（供应链+认证） |
