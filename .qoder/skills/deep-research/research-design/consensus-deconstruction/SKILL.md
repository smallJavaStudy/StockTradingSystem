# 市场共识解构

## 何时使用

- 市场对某个投资命题形成了单一方向的强烈共识
- 一篇研报/一篇文章的逻辑看起来"太顺了"，但直觉告诉你漏了什么
- 需要从一个热点叙事中找到认知差

## 分析步骤

### 1. 提取共识叙事

用一句话写出市场普遍接受的逻辑链，越具体越好：

```
坏例：「存储涨价利好设备」── 太模糊
好例：「存储价格涨 → 晶圆厂盈利改善 → 资本开支增加 → 设备订单爆发」── 每步可检验
```

### 2. 列出隐含假设

逐环节问："这步成立的隐含前提是什么？"

| 逻辑环节 | 隐含假设 |
|---------|---------|
| 价格涨→盈利改善 | 价格涨幅超过成本涨幅 |
| 盈利改善→资本开支 | 盈利转化为Capex的传导不受阻碍 |
| 资本开支→设备订单 | 资本开支增量流向这个设备品类 |

### 3. 识别薄弱环节

对每个隐含假设，问三个问题：
- **有反例吗？** 历史上有没有类似的共识被推翻过的案例？
- **有滞后吗？** 这步传导的时滞是多长？
- **有漏项吗？** 逻辑链跳过了哪些中间环节？

### 4. 构建反证链

对最薄弱的一两个环节，用具体数据构建反证：
- 量化反例（"但实际上XX数据显示..."）
- 条件分析（"只有当XX条件满足时，这步才成立"）

## 输出格式

```
共识叙事: [一句话]
逻辑链:
  环节1 → 环节2 → 环节3 → 环节4
  ^薄弱    ^可检验   ^薄弱    ^可检验

隐含假设:
  H1: [假设1] — [检验结果]
  H2: [假设2] — [检验结果]

薄弱环节: [具体哪个环节+为什么]

反证: [关键反证数据和逻辑]
```

## 典型案例

| 共识 | 薄弱环节 | 反证 |
|------|---------|------|
| 基药目录纳入=放量 | 纳入→处方中间有DRG/医生习惯/患者支付多层过滤器 | 康诺亚185家→1500家，处方量并未等比例增长 |
| 先进封装产能翻倍=利润翻倍 | 名义产能≠有效产能（验证/良率/交付三道门） | 通富微电利润增速可观但资本开支91亿，折旧先行 |
| AI芯片管制=算力链景气下行 | 芯片≠有效算力（封装/HBM/整机/机柜/数据中心五道门） | 管制反而加速国产替代集中，但交付卡在中间环节 |
