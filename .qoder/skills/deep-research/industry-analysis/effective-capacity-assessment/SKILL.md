# 有效产能评估

## 何时使用

- 看到产能规划数字，需要判断有多少能真正兑现
- 市场在按名义产能做线性外推，直觉告诉你有问题
- 需要评估一个扩产计划的含金量

## 核心框架

### 名义产能 → 有效产能：三个过滤器

```
名义产能 (规划数字)
    ↓ 过滤器1: 客户验证
验证产能 (通过客户认证的)
    ↓ 过滤器2: 稳态良率
良率产能 (批次间波动可控的)
    ↓ 过滤器3: 持续交付
有效产能 (能稳定出货的)
```

### 过滤器1：客户验证

- **验证什么**：送样→小批量→批量→正式采购资质
- **周期**：设备进厂到Demo基础验证约3个月，完整验证到正式采购约1.5年
- **关键问题**：产能建好了但送样阶段的产能不是有效产能

### 过滤器2：稳态良率

- **关键概念**：整包良率 = 所有工序良率的乘积
- 一条10道工序的产线，每道良率99%，整包良率 = 0.99^10 ≈ 90%
- 如果某道工序良率降到95%，整包 = 0.95×0.99^9 ≈ 86%
- **单道波动被指数级放大**

### 过滤器3：持续交付

- 批次间一致性
- 交付能力不因某道工序波动而断供
- 客户需要的是稳定可预期的供应，不是时好时坏的产能

## 时间锁判定

| 阶段 | 时间 | 对利润的贡献 |
|------|------|------------|
| 宣布建线 | t+0 | 0 |
| Demo验证 | t+3月 | 0 |
| 正式采购资质 | t+1.5年 | 开始有 |
| 良率爬坡 | t+2年 | 逐步释放 |
| 稳态有效产能 | t+2.5年+ | 充分兑现 |

**核心判断**：今天宣布建线，形成有效产能要等两年甚至更久。其间名义数字可以很漂亮，对利润的贡献近乎为零。

## 输出格式

```
标的/产线: [名称]
名义产能: [数字] — 宣布时间: [日期]
过滤器1（验证）: [通过率] — [预计时间]
过滤器2（良率）: [整包良率估算] — [爬坡曲线]
过滤器3（交付）: [稳定性评估]

有效产能估算: [名义产能 × 估计通过率]
兑现时间线: [什么时候有效产能开始贡献利润]
投资判断: [当前估值是否已price in了名义产能兑现的不确定性]
```
