# 供应链瓶颈分析

## 何时使用

- 市场在笼统地讨论"缺货""紧缺""产能不足"
- 需要识别产业链中真正卡脖子的单一环节
- 判断某个瓶颈是暂时性的还是结构性的

## 分析步骤

### 1. 画出全链路节点

从原材料到终端交付，列出每一个关键节点：

```
原料 → 制造 → 封装 → 集成 → 交付 → 客户
```

### 2. 对每个节点标注约束类型

| 约束类型 | 特征 | 可突破性 |
|---------|------|---------|
| 产能约束 | 有技术、有设备，扩产即可 | 高（资本开支可解决） |
| 技术约束 | 能做但良率不行或规格不够 | 中（需要工程积累） |
| 认证约束 | 能做但客户不认 | 中（需要时间+关系） |
| 供应链约束 | 上游原料/设备被卡 | 低（受制于人） |
| 产业化约束 | 实验室能做，大规模量产不行 | 最低（可能需要多年） |

### 3. 识别最短的板

不是"产能够不够"，而是"整条链中，哪个环节的约束最刚性、突破周期最长？"

### 4. 三种常见的错误归因

| 错误归因 | 正确分析 |
|---------|---------|
| "电力设备缺货" | 变压器缺的是制造工艺（可攀爬），燃气轮机缺的是供应链+认证（硬约束），SOFC缺的是产业化（还没开始） |
| "芯片产能不足" | 芯片造出来了，但卡在先进封装→HBM→整机→机柜→数据中心的中间环节 |
| "材料替代=纯度达标" | 真正卡的是多种材料在同一工艺窗口协同验证的平台能力 |

## 输出格式

```
产业链: [名称]

全链路:
  节点1 [约束类型] [突破周期]
    → 节点2 [约束类型] [突破周期]
    → 节点3 [约束类型] [突破周期] ← 最短的板
    → ...

瓶颈定位: [具体环节+约束类型]
瓶颈性质: [暂时性/结构性/产业化初期]
投资含义: [谁受益于瓶颈/谁受困于瓶颈/什么时候瓶颈缓解]
```

## 典型案例

| 产业链 | 表面共识 | 真实瓶颈 | 投资含义 |
|--------|---------|---------|---------|
| 国产算力 | 芯片管制是最大瓶颈 | 先进封装+HBM+整机交付才是卡点 | 算力链景气不看芯片产量，看整链最短的板 |
| 半导体材料 | 纯度是核心 | 多种材料在同一工艺窗口协同验证是核心 | 平台型公司获得单品企业无法复制的竞争位 |
| HBM测试设备 | 跟随存储周期波动 | HBM让测试投资密度从3亿→20亿/万片，结构性重构 | 测试设备从β品种变为结构性成长品种 |
