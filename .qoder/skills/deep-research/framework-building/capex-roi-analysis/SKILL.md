# 资本开支回报分析

## 何时使用

- 企业正在经历大规模Capex周期
- 需要判断Capex是在创造价值还是在毁灭价值
- 市场对Capex的解读过于简单（"Capex增长=利好"）

## 核心框架

### Capex四类型区分

| 类型 | 特征 | 判断信号 | 投资含义 |
|------|------|---------|---------|
| 需求驱动型 | 订单跑在产能前面 | 在手订单/产能>1.2 | 积极 |
| 供给约束缓解型 | 产能瓶颈制约交付 | 产能利用率>90% | 偏积极 |
| 会计基数型 | 仅因基数低而增速高 | Capex/收入比并未提升 | 中性 |
| 结构切换型 | 投向变了（如从传统→先进） | Capex结构发生显著变化 | 需单独分析 |

### Capex-收入-折旧三角

```
        Capex ──→ 折旧（成本端，立即开始计提）
          │
          ↓ (滞后1.5-2.5年)
        有效产能
          │
          ↓
        收入确认（收入端，滞后更长）
```

**关键洞察**：折旧先释放，收入后兑现。两边节奏差会体现在利润表上。

### 收入兑现斜率 vs 资本开支侵蚀斜率

```
判断值 = 收入兑现斜率 / 折旧侵蚀斜率

> 1.5：Capex在创造价值（收入增速跑赢折旧增速）
1.0-1.5：临界区域（需要紧监控）
< 1.0：Capex在毁灭价值（折旧跑在了收入前面）
```

### Capex见顶是真拐点还是假拐点？

| 信号 | 含义 |
|------|------|
| Capex增速下降 + ARR/RPO还在增长 | 假拐点（可能是节奏调整） |
| Capex增速下降 + ARR/RPO也在下降 | 真拐点（需求见顶） |
| Capex/收入比下降 + 收入增速加速 | 黄金交叉（效率拐点） |
| Capex/收入比上升 + 收入增速减速 | 警示信号（Capex效率恶化） |

## 历史参照

| 案例 | 发生了什么 | 教训 |
|------|-----------|------|
| 互联网泡沫光纤 | 先修路后等车，需求跟不上，折旧成利润杀手 | Capex先行≠需求会跟上 |
| AWS | 持续加厚服务层和生态锁定，折旧压力被高毛利服务消化 | Capex+生态锁定可以把基础设施熬成利润池 |
