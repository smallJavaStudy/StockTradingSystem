# 多维度结论收敛

## 何时使用

- 完成了3个独立维度的研究（按topic-decomposition的框架）
- 需要从多个维度的分析中收敛为一个统一的投资判断
- 各维度的结论可能存在矛盾，需要权衡

## 收敛四步法

### 1. 列出各维度结论

| 维度 | 核心结论 | 方向 | 置信度(1-10) |
|------|---------|------|-------------|
| 维度1 | [一句话] | 看多/中性/看空 | |
| 维度2 | [一句话] | 看多/中性/看空 | |
| 维度3 | [一句话] | 看多/中性/看空 | |

### 2. 识别交叉验证

三个维度之间的互相验证：

- **一致性**：两个以上维度指向同一方向 → 高置信度
- **独立性**：每个维度的结论不受其他维度影响 → 无循环论证
- **互补性**：三个维度各自覆盖了课题的不同侧面 → 全面

### 3. 处理矛盾

如果维度间结论矛盾：

- 矛盾来自不同的时间维度？（短期vs长期）
- 矛盾来自不同的假设？（哪个假设更可靠）
- 矛盾是因为某个维度的数据不完整？

**处理原则**：不追求一致，追求理解矛盾的本质。有时矛盾本身就是最有价值的发现。

### 4. 加权综合

| 因素 | 考虑 |
|------|------|
| 置信度 | 数据更完整、逻辑更严密的维度权重更高 |
| 时效性 | 最新数据的维度更有参考价值 |
| 不对称性 | 如果上行空间远大于下行风险，即使多个维度偏中性也可能偏看多 |

## 输出格式

```
课题: [课题名称]

维度汇总:
  维度1: [结论] | 方向: [看多/中性/看空] | 置信度: [1-10]
  维度2: [结论] | 方向: [看多/中性/看空] | 置信度: [1-10]
  维度3: [结论] | 方向: [看多/中性/看空] | 置信度: [1-10]

交叉验证:
  一致点: [哪些维度指向同一方向]
  矛盾点: [矛盾在哪里 + 可能的原因]
  
综合判断:
  方向: [看多/看空/中性]
  置信度: [高/中/低]
  一句话理由: [不超过50字]
  
关键条件:
  [综合判断成立的前提条件，1-2条]
```
