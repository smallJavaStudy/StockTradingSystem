# 结构化报告生成

## 何时使用

- 完成了深度研究，需要输出一份正式的研究报告
- 需要让研究成果可被他人理解和使用
- 需要将复杂的分析过程压缩为可执行的投资建议

## 标准报告结构

### 1. 核心判断（500字以内）

一句话说清这个报告在回答什么问题、结论是什么。

```
核心问题：[一句话]
市场共识：[市场和主流报告怎么看的]
我们的判断：[我们的不同看法]
关键认知差：[我们和市场最大的分歧在哪里]
```

### 2. 三条思维链（每条独立成章）

对应 topic-decomposition 拆解出的三个维度：

```
思维链1：[维度名称]
  - 研究了什么问题
  - 用了什么方法/数据
  - 核心发现
  - 对投资判断的贡献

思维链2：[维度名称]
  ...同上

思维链3：[维度名称]
  ...同上
```

每条思维链应：
- 独立可读（不依赖其他思维链）
- 有具体数据支撑（不是纯叙事）
- 对最终结论有明确贡献

### 3. 风险提示

| 风险 | 性质 | 触发条件 | 影响程度 |
|------|------|---------|---------|
| [风险1] | 结构性/周期性/政策 | [什么情况会发生] | 高/中/低 |
| [风险2] | | | |

**原则**：只列具体风险，不列"市场风险""政策风险"这类泛泛的。

### 4. 标的映射

如果报告涉及具体投资标的：

| 标的 | 映射逻辑 | 受益确定性 | 风险点 |
|------|---------|-----------|--------|
| [标的1] | [为什么这个报告利好/利空这个标的] | 高/中/低 | |
| [标的2] | | | |

### 5. 验证日历

列出未来3-12个月应该关注的验证节点：

| 时间 | 验证事件 | 关注什么数据 | 好的结果 | 坏的结果 |
|------|---------|------------|---------|---------|

## 质量标准

- 核心判断可以在1分钟内讲清楚
- 每条思维链可以在3分钟内讲清楚
- 风险提示是具体的、可检验的
- 标的映射有直接的逻辑链接（不是生拉硬扯）

## 完整模板

```markdown
# [课题标题]

## 核心判断
[一段话，不超过500字]

## 思维链1：[维度名]
[正文]

## 思维链2：[维度名]
[正文]

## 思维链3：[维度名]
[正文]

## 风险提示
| 风险 | 性质 | 触发条件 | 影响 |
|------|------|---------|------|

## 标的映射
| 标的 | 逻辑 | 确定性 | 风险 |
|------|------|--------|------|

## 验证日历
| 时间 | 事件 | 关注数据 |
|------|------|---------|
```
